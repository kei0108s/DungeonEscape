# DungeonEscape

## ① ゲーム概要

Dungeon Escapeは、ダンジョン内に設置されたギミックを解きながら出口を目指す、3D脱出ゲームです。

C++の学習を目的として個人で制作し、ドアの開閉やアイテムの判定、トリガーによるギミックの制御など、ゲーム進行に必要な処理をC++で実装しました。

## ④ クリアまでのルート

ダンジョン内を探索し、アイテムやギミックを利用して進行に必要な仕掛けを解除しながら出口を目指します。

**具体的な攻略手順**

1. 【スタート地点から正面の白くライトアップされているスイッチを踏み続ける】
2. 【左の鉄格子が下りるので急いで、白くライトアップされている銅像を取得】
3. 【最初の部屋を出て、左側に白くライトアップされている台座に設置】
4. 【進んでいき、奥で黄色くライトアップされている銅像を取得】
5. 【ひとつ前の部屋に戻って、黄色くライトアップされている台座に設置】
6. 【奥の壁が移動するので外に出るとクリア】

## ⑤ 実装した機能

### ドアの制御

ゲーム内のギミックと連動して、ドアの状態を変更する処理を実装しました。

### アイテムの判定

プレイヤーによるアイテムの取得・設置に関する判定処理を実装しました。

### トリガーの管理

ギミックを動作させるためのトリガー処理を実装しました。ほかの処理と連携し、ゲーム内の仕掛けを制御しています。

## ⑥ 技術的な工夫

### クラス・コンポーネントの役割分担

ギミックに関する処理を一つのクラスにまとめるのではなく、Lock・Trigger・Moverに役割を分けて実装しました。

それぞれの処理を独立させることで、機能ごとの役割を明確にし、修正や機能追加がしやすい構成を意識しました。

### 再利用を意識した設計

各ギミックの状態を変更するための関数を用意し、別のギミックでも処理を利用できる構造にしました。

ギミックごとに同じ処理を作り直すのではなく、既存のクラスやコンポーネントを組み合わせて機能を実装できるようにすることを意識しました。
